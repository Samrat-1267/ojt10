# TechForge Website

Static TechForge PC shopping website added under `site/`.

Features:
- Premium dark gaming UI
- Product search and category filters
- Product images matched to product names
- Nepal Rupee (NPR) prices
- Interactive PC builder
- Build total calculator
- Cart counter
- Responsive layout
- GitHub Pages deployment workflow

Prices are sample Nepal market values and should be verified before real sales. A 2026 Nepal PC-price guide reports market ranges that can be used as a reference: https://electronestnepal.com/build-your-own-pc-in-nepal-2026-parts-price-list-and-complete-guide/
